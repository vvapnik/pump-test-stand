Wiring diagram - CH32V003

Schematic for the CH32V003F4P6 (TSSOP-20) instead of the ATmega328: the same peripherals (ACS712-20A with an RC filter, pump MOSFET switch with a flyback diode, LCD1602 over I2C, encoder, start/stop button), plus programming via an Arduino Uno (Ardulink/SWIO) - exactly as already verified in hardware. All pins and the mode were tested on the real stand.

Already verified in hardware: power/SWIO/NRST (successful flash), LCD over I2C, encoder + buttons (select→edit→commit mode), PWM on pin 14 (with an LED). ACS712/MOSFET/pump - per this schematic, not powered up yet.
Common ground. The 5V circuit (MCU, LCD, encoder, Uno) and the 12V circuit (pump) must share one common GND - otherwise ACS712 readings will be random.
